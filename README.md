# Diplom_2
Автоматизированные тесты API для сервиса управления заказами 

## Стек технологий
* **Язык:** Python 3.14
* **Фреймворк:** PyTest
* **HTTP‑клиент для API‑запросов:** requests
* **Отчётность:** Allure
* **Генерация тестовых данных:** Faker

## Структура проекта

    Diplom_2/
        ├── allure_results/             # Отчет
        ├── constants/                  # Константы: коды ответов, эндпоинты
        │   ├── api_constants.py
        │   └── endpoints.py
        ├── helpers/                    # Вспомогательные функции и данные для тестов
        │   ├── auth_helpers.py         # Аутентификация
        │   ├── data.py                 # Тестовые данные
        │   ├── order_api.py            # API‑методы для работы с заказами
        │   └── user_api.py             # API‑методы для работы с пользователями
        ├── tests/                      # Тестовые сценарии
        │   ├── test_create_user.py     # Тесты создания пользователя
        │   ├── test_login_user.py      # Тесты авторизации пользователя
        │   └── test_create_order.py    # Тесты создания заказов 
        ├── conftest.py                 # Фикстуры
        ├── README.md
        └── requirements.txt

## Назначение ключевых компонентов
**constants/** — централизованное хранение констант:
 - `api_constants.py`: HTTP‑коды (например, `HTTP_200_OK`, `BAD_REQUEST`);
 - `endpoints.py`: URL‑эндпоинты API.

**helpers/** — переиспользуемые функции:
 - API‑методы (`order_api.py`, `user_api.py`) для отправки запросов;
 - вспомогательные утилиты (`auth_helpers.py`) и тестовые данные (`data.py`).

**tests/** — тестовые сценарии:
 - создание и авторизация пользователей;
 - создание заказов с разными параметрами (с токеном/без, с ингредиентами/без, с некорректными данными).

**conftest.py** — фикстуры pytest для:
 - создания тестовых пользователей;
 - получения токенов авторизации; 
 - подготовки тестовых данных (например, списков ингредиентов).

## Запуск тестов
Установите зависимости (если ещё не установлены):
 - `pip install pytest allure-pytest requests`

Запустите тесты:
 - `pytest tests/ --alluredir=allure_results`

Сгенерируйте отчёт Allure:
 - `allure serve allure_results/`
